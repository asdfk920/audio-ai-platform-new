GET /list 获取内容列表（分页、排序、筛选）
📝 接口描述

分页获取音频内容列表，支持多种筛选和排序方式。

功能特性：

  • ✅ 分页查询（默认每页20条）
  • ✅ 多维度排序（综合/最新/最热/推荐）
  • ✅ 分类和标签过滤
  • ✅ 关键词模糊搜索
  • ✅ VIP内容标识
📥 请求参数 (Query)
参数名类型必填默认值说明
page integer 可选 1 页码（最小值1）
page_size integer 可选 20 每页数量（1-100）
category_id integer 可选 - 分类ID过滤
tag_ids string 可选 - 标签ID（多个用逗号分隔：1,2,3）
title string 可选 - 标题模糊查询
keyword string 可选 - 关键词搜索（标题+艺术家）
sort integer 可选 0 排序：0-综合 1-最新 2-最热 3-推荐
is_vip integer 可选 0 VIP专享：0-全部 1-仅VIP
📤 响应示例 (200 OK)
{ "code": 200, "msg": "success", "data": { "total": 150, "page": 1, "page_size": 20, "has_more": true, "list": [ { "content_id": 1001, "title": "晴天", "artist": "周杰伦", "cover_url": "https://cdn.example.com/cover/1001.jpg", "duration": 269, "view_count": 1250000, "like_count": 85000, "is_vip_content": false, "can_play": true } ] } }
GET /{id} 获取内容详情（权限、播放地址）
📝 接口描述

根据内容ID获取详细信息，包括基本信息、权限信息、统计数据等。

📥 路径参数
参数名类型必填说明
id integer (int64) 必填 内容唯一ID
📤 响应示例 (200 OK)
{ "code": 200, "msg": "success", "data": { "content_id": 1001, "title": "晴天", "artist": "周杰伦", "album": "叶惠美", "duration": 269, "permission": { "need_vip": false, "can_play": true, "can_download": true }, "play_url": "https://stream.example.com/music/1001.mp3" } }
POST /{id}/like 点赞/取消点赞切换
📝 接口描述

对指定内容进行点赞或取消点赞操作。

业务规则：

  • ✅ 首次调用 = 点赞
  • ✅ 再次调用 = 取消点赞
  • ✅ 返回当前状态和总点赞数
📥 路径参数
参数名类型必填说明
id integer (int64) 必填 内容ID
📤 响应示例 (200 OK)
// 点赞成功 { "code": 200, "data": { "success": true, "message": "点赞成功", "liked": true, "like_count": 85001 } } // 取消点赞 { "code": 200, "data": { "success": true, "message": "已取消点赞", "liked": false, "like_count": 85000 } }
POST /{id}/favorite 收藏/取消收藏（歌曲/歌单/专辑）
📝 接口描述

将指定内容添加到收藏夹或从收藏夹移除。

支持的收藏类型：

  • song (默认) - 收藏歌曲
  • playlist - 收藏歌单
  • album - 收藏专辑
📥 路径参数
参数名类型必填说明
id integer (int64) 必填 内容ID
📤 响应示例 (200 OK)
{ "code": 200, "data": { "success": true, "message": "收藏成功", "favorited": true, "favorite_count": 1200 } }
POST /playlists 创建新歌单
📝 接口描述

创建一个新的用户自定义歌单。

注意事项：

  • ⚠️ 名称长度限制：1-100字符
  • ⚠️ 描述长度限制：最多500字符
  • ✅ 可设置公开/私密权限
📥 请求体 (JSON)
参数名类型必填默认值说明
name string 必填 - 歌单名称（1-100字符）
description string 可选 - 歌单描述（最多500字符）
cover_url string (uri) 可选 - 封面图片URL
is_public boolean 可选 true 是否公开（true=公开, false=私密）
{ "name": "我的最爱", "description": "精选好听的华语流行歌曲", "is_public": true }
📤 响应示例 (201 Created)
{ "code": 201, "data": { "id": 5001, "name": "我的最爱", "song_count": 0, "is_public": true, "created_at": "2024-01-20T15:30:00Z" } }
PUT /playlists/{id} 编辑歌单信息
📝 接口描述

更新已有歌单的基本信息（名称、描述、封面、公开性）。

📥 路径参数
参数名类型必填说明
playlistId string 必填 歌单ID
📥 请求体 (JSON) - 可选字段
参数名类型说明
namestring歌单名称（1-100字符）
descriptionstring歌单描述（最多500字符）
cover_urlstring (uri)封面图片URL
is_publicinteger可见性（0=私有, 1=公开）
📤 响应示例 (200 OK)
{ "code": 200, "data": { "id": 5001, "name": "我的超级最爱", "song_count": 25, "updated_at": "2024-01-21T10:15:00Z" } }
DELETE /playlists/{id} 删除歌单
📝 接口描述

删除指定的用户歌单及其所有歌曲关联数据。

⚠️ 重要提示：

  • ❌ 此操作不可逆
  • ❌ 会同时删除歌单内所有歌曲的关联关系
📥 路径参数
参数名类型必填说明
playlistId string 必填 歌单ID
📤 响应示例 (200 OK)
{ "code": 200, "data": { "success": true, "message": "歌单已成功删除" } }
POST /playlists/{id}/songs 批量添加歌曲
📝 接口描述

将一首或多首歌曲添加到指定歌单中。

业务规则：

  • ✅ 支持批量添加（一次最多50首）
  • ✅ 自动去重（同一首歌不会重复添加）
  • ✅ 实时更新歌单歌曲计数
📥 路径参数
参数名类型必填说明
playlistId string 必填 目标歌单ID
📥 请求体 (JSON) - 二选一
参数名类型说明
content_idinteger (int64)单个歌曲ID
content_idsarray[integer]批量歌曲ID列表
// 单曲添加 { "content_id": 1001 } // 批量添加 { "content_ids": [1001, 1002, 1003] }
📤 响应示例 (200 OK)
{ "code": 200, "data": { "success": true, "message": "已添加1首歌曲到歌单", "added_count": 1, "duplicate_count": 0 } }
DELETE /playlists/{id}/songs/{songId} 移除歌曲
📝 接口描述

从指定歌单中移除特定歌曲。

注意事项：

  • ✅ 仅移除关联关系，不删除原歌曲
  • ✅ 实时更新剩余歌曲数统计
📥 路径参数
参数名类型必填说明
playlistId string 必填 歌单ID
songId string 必填 要移除的歌曲ID
📤 响应示例 (200 OK)
{ "code": 200, "data": { "playlist_id": "5001", "remain_total": 24 } }

📊 核心数据模型

ContentListItem - 内容列表项

{
  content_id: integer (int64),     // 内容唯一ID
  title: string,                   // 歌曲名称
  artist: string,                  // 歌手/艺术家
  album: string,                   // 专辑名称
  cover_url: string (uri),         // 封面图URL
  duration: integer,               // 时长（秒）
  view_count: integer (int64),     // 播放量
  like_count: integer (int64),     // 点赞数
  is_vip_content: boolean,         // 是否VIP专享
  can_play: boolean,               // 是否可播放
  vip_level: integer               // 所需会员等级
}

PermissionInfo - 权限信息

{
  need_vip: boolean,               // 是否需要VIP
  required_level: integer,         // 所需会员等级（0=免费）
  can_play: boolean,               // 是否可播放
  can_download: boolean            // 是否可下载
}

PlaylistResponse - 歌单响应

{
  id: integer (int64),             // 歌单ID
  name: string,                    // 歌单名称
  description: string,             // 歌单描述
  cover_url: string (uri),         // 封面图片URL
  song_count: integer,             // 歌曲数量
  is_public: integer,              // 是否公开（0=私有, 1=公开）
  user_id: integer (int64),        // 创建人ID
  created_at: string (datetime),   // 创建时间
  updated_at: string (datetime)    // 更新时间
}

🎯 核心接口一览

  • POST /device/register - 设备注册/激活（首次使用必调）
  • POST /device/auth - 获取JWT Token（30天有效）
  • GET /device/ws - 建立WebSocket长连接
  • POST /device/cmd/play - 播放控制指令（播放/暂停/停止/上下首）
  • POST /device/cmd/pause - 暂停播放指令
  • POST /device/cmd/play-audio - 点播指令（支持DRM）
  • POST /device/cmd/volume-up - 增加音量（±20范围）
  • POST /device/cmd/volume-down - 降低音量
  • POST /device/cmd/reboot - 远程重启设备
  • POST /device/download/song - 下载歌曲（支持DRM透传）
